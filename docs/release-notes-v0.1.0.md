# PathPilot v0.1.0

PathPilot v0.1.0 is the first public preview of the keyboard-first GTK4 file
manager. It delivers a practical local-file workflow built around fast
three-column navigation, responsive previews, Vim-inspired commands, and native
desktop integration.

Highlights include Visual multi-selection and safe batch operations, searchable
commands, persistent layouts and locations, Git-aware status information,
bookmarks, MIME-aware Open With history, text path copying, and an embedded
Neovim session that turns the preview pane into a full editor for quick changes.

This release targets Fedora and Wayland first. It is ready for daily testing,
but remains a preview: packaging, remote filesystems, tabs, filtering,
accessibility review, and broader desktop validation are future work.

Build requirements and usage instructions are available in the repository
README. Fedora users need GTK 4.12+, GTK4 VTE development files, Rust, and
Neovim for embedded editing.
